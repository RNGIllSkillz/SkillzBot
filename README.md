## 🧑‍🤝‍🧑 Команды для всех

Эти команды доступны любому пользователю в чате.

| Команда | Описание | Формат | Cooldown |
|--------|----------|--------|----------|
| `!help` | Показать список команд | `!help` | 120 сек |
| `!ttvgg` | Получить свою статистику в чате | `!ttvgg` | 600 сек |
| `!clip` | Создать клип на Twitch | `!clip` | 600 сек |
| `!lp` | Показать League Points | `!lp` или `!lp SummonerName Tag Region` *(для модов и выше)* | 60 сек |
| `!opgg` | Профиль на OP.GG | `!opgg` | 600 сек |
| `!топ` | Топ активных пользователей в чате | `!топ` | 4800 сек |
| `!ртоп` | Топ победителей рулетки | `!ртоп` | 4800 сек |
| `!quizz` | Начать викторину | `!quizz` | 4800 сек |
| `!song` | Отображает текущую песню | `!song` | 60 сек |
| `!sr` | Отправить медиа/трек в очередь за быллы викторины (стоимость 2 балла) | `!sr` | 60 сек |
| `!points` | Показать количество очков/поинтов | `!points` | 600 сек |
| `!mmr` | Показать рейтинг MMR | `!mmr` | 4800 сек |
| `!история` | История матчей игрока | `!история` | 1800 сек |
| `!очередь` | Текущая очередь треков | `!очередь` | 240 сек |
| `!рулетка` | Игра в рулетку | `!рулетка` | Внутренний кулдаун |

## 🛡️ Команды модераторов

Команды, доступные модераторам канала.

| Команда | Описание | Формат | Cooldown |
|--------|----------|--------|----------|
| `!antibot` | Уровень защиты от ботов | `!antibot [0-5]` | 10 сек |
| `!prediction` | Запуск или остановка предсказания | `!prediction on` / `off` | – |
| `!lang` | Сменить язык бота | `!lang ru` или `!lang en` | – |
| `!silent` | Вкл/выкл "тихий режим" | `!silent` | – |
| `!unban` | Разблокировать пользователя | `!unban username` | – |
| `!chatfilter` | Уровень фильтрации сообщений | `!chatfilter [0–5]` | – |
| `!getmods` | Список всех зарегистрированных модераторов | `!getmods` | – |

### Уровни `!chatfilter`:
0 – Ничего не делать
1 – Удалить сообщение
2 – Удалить + уведомить модераторов
3 – Тайм-аут на 24 часа
4 – Тайм-аут на неделю
5 – Перманентный бан

## 🔐 Команды администратора (Root)

Доступны только владельцу бота.

| Команда | Описание |
|--------|----------|
| `!test` | Вызов тестовой команды |
| `!jobs` | Запуск фоновых задач |
| `!deleteall` | Очистка чата |
| `!ping` | Проверка ответа бота |
| `!getallrewards` | Показать все награды канала |
| `!find` | Найти пользователя |
| `!trackuser` | Вывести в файл все сообщения пользователя из всех DB |

### Управление наградами:

| Команда | Формат |
|--------|--------|
| `!enablereward` | `!enablereward rewardID` или `!enablereward "название" "текст"` |
| `!disablereward` | `!disablereward rewardID` или `!disablereward "название" "текст"` |
| `!updatereward` | `!updatereward ID "название" цена "подсказка" включено userInput` |
| `!createreward` | `!createreward "название" цена "подсказка" включено userInput` |
| `!deletereward` | Удалить награду по ID или названию |

### Модераторы и VIP:

| Команда | Описание |
|--------|----------|
| `!addmod`, `!deletemod` | Добавить / удалить модератора |
| `!addvip`, `!deletevip` | Добавить / удалить VIP |
| `!addwhite [слово]` | Добавить слово в белый список |
| `!debug` | Переключить отладку |

### Подписка:

| Команда | Описание |
|--------|----------|
| `!sub` | Загрузить подписочную информацию |
| `!subcheck` | Проверить подписку пользователя |

### Whisper от имени стримера:

| Команда | Формат |
|--------|--------|
| `!шептун` | `!шептун username сообщение` |
