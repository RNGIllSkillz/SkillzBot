## Команды для чата (Twitch)

Команды доступны всем пользователям, если не указано иное.

| Команда | Описание | Кулдаун |
|--------|----------|----------|
| `!help` | Показать справку по командам | 120 с |
| `!lp` | Показать текущий ранг, LP и статистику (Win/Loss) в LoL | 60 с |
| `!opgg` | Ссылка на профиль призывателя на OP.GG | 600 с |
| `!mmr` | Приблизительный MMR призывателя (через WhatIsMyMMR) | 4800 с |
| `!ttvgg` | Ваша статистика на канале (сообщения, винстрик в рулетке, баллы) | 600 с |
| `!clip` | Создать клип момента на стриме (Global CD) | 600 с |
| `!топ` | Топ-3 самых активных писателей в чате | 4800 с |
| `!ртоп` | Топ-3 победителей в рулетку | 4800 с |
| `!quizz` | Показать статус или запустить викторину (Global) | 4800 с |
| `!points` | Показать ваши баллы канала и очки викторины | 600 с |
| `!история` | История прошлого матча | 1800 с |
| `!sr` | Заказ трека за баллы викторины (требуется ссылка или название) | 60 с |
| `!рулетка` | Испытать удачу (можно получить таймаут или винстрик) | Индив. |
| `!ставки` | Информация о текущей ставке (текст задается стримером) | 120 с |

## Команды Модераторов

| Команда | Описание |
|--------|----------|
| `!antibot [0-2]` | Установить уровень защиты от ботов (0=Выкл, 1=Слабый, 2=Сильный) |
| `!prediction` | Управление авто-ставками. `!prediction on` / `off` |
| `!lang` | Сменить локаль бота (`ru`, `eng`, `fr` и др.) |
| `!silent` | Включить/выключить "тихий режим" (бот перестает отвечать в чат) |
| `!chatfilter [0-5]` | Уровень фильтрации чата (0=Выкл ... 5=Бан) |
| `!unban [user]` | Удалить пользователя из локального черного списка бота |
| `!getmods` | Показать список всех модераторов канала |
| `!lp [nick] [tag] [region]`| Проверить ранг другого игрока (регионы: `euw`, `ru`, `na`) |

### Уровни ChatFilter:
0. Бездействие
1. Удаление сообщения
2. Удаление + Уведомление модераторов (Whisper)
3. Таймаут 24 часа
4. Таймаут 1 неделя
5. Перманентный бан

## Команды Администратора (Root)

Доступны только root-пользователю. Его логин задан в коде (`BotConfigurationFactory`), а не в конфиге.

### Управление

| Команда | Описание |
|--------|----------|
| `!test` | Тестовая команда (вывод в консоль) |
| `!jobs` | Показать активные фоновые задачи (Quartz) |
| `!deleteall` | Полная очистка чата (Clear Chat) |
| `!ping` | Проверка работоспособности (ответ `pong`) |
| `!find [user]` | Полная информация о пользователе из БД (ID, флаги, статы) |
| `!trackuser [user]` | Выгрузить все сообщения пользователя из БД в текстовый файл |
| `!sudo [user]` | Алиас для `!trackuser` |
| `!debug` | Включить расширенное логирование в чат/консоль |
| `!reloadfilters` | Перезагрузить списки запрещенных слов без перезапуска бота |

### Управление Наградами (Channel Points)

| Команда | Формат / Описание |
|--------|-------------------|
| `!getallrewards` | Список всех наград канала и их ID |
| `!enablereward` | `!enablereward [id]` или `!enablereward "название" "текст"` |
| `!disablereward` | `!disablereward [id]` |
| `!updatereward` | `!updatereward [id] "название" [цена] "подсказка" [вкл/выкл] [ввод_текста]` |
| `!createreward` | `!createreward "название" [цена] "подсказка" [вкл/выкл] [ввод_текста]` |
| `!deletereward` | Удалить награду (в разработке) |

### Управление Ролями

| Команда | Описание |

| `!addmod [user]` | Дать модерку (через API Twitch) |
| `!deletemod [user]` | Снять модерку |
| `!addvip [user]` | Дать VIP |
| `!deletevip [user]` | Снять VIP |
| `!addwhite [слово]` | Добавить слово в белый список фильтра |
| `!sub` | Добавить месяц подписки вручную |
| `!subcheck` | Проверить статус подписки |

## Discord Команды

Команды, которые работают в привязанном Discord-канале (`DiscordSpamID`). Discord-клиент запускается при старте бота, если в конфиге заданы `DiscordBotToken` и `DiscordNoteID`.

| Команда | Описание |
|--------|----------|
| `!lp` / `!лп` | Показать ранг стримера. Можно указать `!lp [nick] [tag] [region]` |
| `!8ball [вопрос]` | Магический шар (ответы "Да", "Нет" и т.д.) |
| `!say [текст]` | Отправить сообщение в Twitch-чат от имени бота |
| `!gpt` | (В разработке) Запрос к ChatGPT |

## Фильтр запреток (dic.txt / dicWhiteList.txt)

Оба словаря лежат в общей папке `Channels_Data/_shared/`, по одному слову на строку. Перед сравнением и слова словарей, и сообщения приводятся к одному виду:

- регистр не учитывается (`ПИДОР` = `пидор`);
- диакритика, zalgo и невидимые символы убираются;
- латиница читается двумя способами: по звучанию (`pidor` -> `пидор`) и по форме (`nugop` -> `пидор`), цифры `0 1 3 4 6` и `@` читаются как буквы;
- повторы букв схлопываются (`пииидоор` -> `пидор`), знаки препинания игнорируются.

Слова из `dicWhiteList.txt` маскируются внутри слова до поиска запретки, поэтому `книга` и `спидран` не срабатывают. Запретка, разбитая пробелами (`п и д о р`, `пи дор`), ловится; обычные соседние слова (`не грусти`, `выспи дорого`) запреткой не считаются. Чтобы ловить латинские написания, которые не читаются как транслит, добавляйте их в `dic.txt` как есть. После правки словарей выполните `!reloadfilters`.

## Сборка

```
dotnet build -c Release
dotnet publish -c Release
```

Проект собирается под `net6.0` и публикуется как самодостаточный single-file для `linux-x64`. Канал выбирается переменной окружения `ENV_CHANNEL_NAME`; конфиг ожидается в `Channels_Data/<канал>/DATA/<канал>.ini`. Логи пишутся в `Channels_Data/<канал>/DATA/logs/bot-YYYYMMDD.log` с ротацией по дням.
